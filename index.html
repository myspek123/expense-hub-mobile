Your PC's real reports, synced every 30 minutes. Tap one to see its expenses.

Everything this phone captured, and where it has got to. Tap one to view or edit it. Nothing is lost if the phone loses signal. A line stays here until the PC has it in a report. A capture with no report yet stays for as long as it takes, so nothing is ever quietly dropped.

Only the report types for the chosen profile show in Add expense.

Paste the deployment URL from the Apps Script setup here once, on this phone, one time. If you update apps-script.gs, redeploy from Manage deployments so this same URL keeps working.

The sync code is the same shared code typed into the PC's own settings. Leave blank until your PC tells you one has been set up.
